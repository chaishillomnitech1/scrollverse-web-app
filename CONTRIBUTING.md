## Sovereign Contribution Guidelines

Thank you for your interest in contributing to the ScrollVerse Trinity Empire.
All contributions must align with the sovereign mission: **erase scarcity, activate sovereignty, serve humanity.**

### Before You Contribute

1. Read the [LICENSE](./LICENSE) — all contributions become property of the ScrollVerse Empire
2. Read the [SECURITY.md](./SECURITY.md) — security-first development
3. Open an issue first for major features — discuss before building

### Development Standards

- All code must pass `pnpm test` (16/16 tests minimum)
- Follow the tRPC-first architecture — no raw fetch/Axios
- All new pages must be wired in `App.tsx` and linked in `Home.tsx` nav
- All assets must be uploaded via `manus-upload-file --webdev` — no local media files
- TypeScript strict mode — no `any` types without justification

### Commit Message Format

```
[SOVEREIGN] feat: add JME character NFT vault
[SOVEREIGN] fix: resolve Junior Movies 404 route
[SOVEREIGN] docs: update master link list
```

### Pull Request Process

1. Fork the repository
2. Create a feature branch: `git checkout -b sovereign/feature-name`
3. Commit with sovereign prefix
4. Ensure all tests pass
5. Submit PR with description of changes and alignment with empire mission

### Code of Conduct

All contributors must operate with:
- **Agape Love** — respect for all contributors and users
- **Sovereign Integrity** — honest, transparent work
- **Positive Impact** — every line of code serves the mission
