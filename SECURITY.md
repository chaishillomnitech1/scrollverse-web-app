## 🔐 Security Architecture

### Platform Security
- **Authentication:** Manus OAuth 2.0 with JWT session signing
- **Transport:** HTTPS/TLS enforced on all endpoints
- **API Security:** tRPC with server-side validation on all procedures
- **Database:** Parameterized queries via Drizzle ORM (no raw SQL injection vectors)
- **Secrets:** All credentials managed via environment variables, never committed
- **Headers:** Security headers enforced (CSP, HSTS, X-Frame-Options)

### Blockchain Security
- **Smart Contracts:** Audited before mainnet deployment
- **Wallet Integration:** Non-custodial — we never hold user private keys
- **NFT Metadata:** Immutable IPFS storage via Pinata gateway
- **Token:** $LONDC on Polygon — contract address published and verified

### Data Protection
- **User Data:** Minimal collection, encrypted at rest
- **Payment Data:** Processed exclusively via Stripe — PCI DSS compliant
- **GDPR/CCPA:** Compliant data handling and deletion on request
