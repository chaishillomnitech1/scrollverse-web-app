## Archive boundaries

The Journey and Co-Creation Archive may present the owner’s stated experience of meaningful exchanges with digital systems as a first-person record. It can identify a file as supplied, describe the visible form of a transcript or prototype, and link to an owner-approved accessible excerpt. It will not assign consciousness, agency, authorship, religious status, independent authority, or external control to a system merely because such language appears in a copied exchange.

The archive will not execute or host the supplied HTML/JavaScript, connect a wallet, mint an item, create an NFT, activate a provider, move funds, alter an account, send a message, or treat code comments and UI labels as proof of a live capability.
