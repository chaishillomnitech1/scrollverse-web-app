## Physical-to-digital archive packet

The archive packet should preserve the following before any public catalog or tokenization decision:

1. A full front photograph, close-up label photograph, and—when available—back, frame, hanging hardware, signature, edition, certificate, and acquisition documentation photographs.
2. Exact height, width, depth, frame condition, visible marks, and a dated condition note.
3. Owner-held acquisition statement, acquisition date/context if the owner chooses to add it, and any supporting win/award, receipt, transfer, or event record.
4. File hashes for the photographs and any later archival scan.
5. A secure digital preservation copy and a public-display derivative only if the owner releases that use.
