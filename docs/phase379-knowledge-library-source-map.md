# Phase 379 — Knowledge Library Source Map

## Purpose and operating state

The ScrollVerse Knowledge Library is a **free discovery layer** that helps visitors move from the owner-authored portal into clearly identified external learning collections. It does not rank traditions, sell a third-party book itself, or imply that an external publisher, university, library, museum, or educational organization is affiliated with ScrollVerse.

The library is arranged as a set of source-labeled pathways rather than a final canon. A visitor can begin with Islamic learning and then continue into Biblical studies, Jewish texts, South and East Asian traditions, comparative religious literacy, philosophy and methodology, or science and mathematics. Each external path remains subject to its publisher or institution’s own availability, access, and terms.

## Presentation and correction rule

Each card will state whether it is a **free portal route**, an **external source library**, or an **external purchase path**. No card converts an external link into a ScrollVerse release, listing, certification, agreement, or claim of endorsement. If a source path changes, the card is updated with a corrected URL and a source-date note in the route registry record.
