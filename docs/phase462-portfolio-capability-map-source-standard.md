# Phase 462 — Portfolio Capability Map Source Standard

**Purpose:** Define the source-labeled way to connect publicly visible ScrollVerse portfolio material to the Companion Hub, Art Learning Studio, Knowledge Commons, and Asset Registry.

## Verified public-source observations

The public `chaishillomnitech1` GitHub profile identifies **Chais Hill**, links to `scrollverse.co`, and currently displays **74 repositories** in the browser-visible profile view.[1] That is an interface observation at the time of review, not a statement about private repositories, deployment state, account access, or external integrations.

The public `scrollverse-omni-manifesto` repository describes itself as a reader-directed source index and release boundary. Its README states that source records are not themselves evidence of a deployed service, active product, payment method, token sale, contract, payout, or financial result. It also distinguishes an unauthenticated public-API subset from a user-supplied total-repository account view and retains separate license boundaries for linked material.[2]

## Capability-map standard

| Field | Requirement |
| --- | --- |
| Source label | Name the public profile, repository, site, documentation page, or tool card exactly |
| Source URL and date | Preserve a direct public URL and the review date/context |
| Visible capability | Describe only what the public source visibly states or contains |
| License/access note | Link the visible license, contribution, or access signal; otherwise label it as not established |
| Scope note | State what the source does **not** establish: private access, deployment, commercial availability, provider integration, or production outcome |
| Connection | Link to the relevant local ScrollVerse route or original learning lesson |
| Correction | Preserve updated source evidence rather than silently replacing the prior card |

## Public-source versus live-integration rule

A public repository, project README, workflow, license, visual demo, website, social profile, or external tool link can be a source card. It does not create a live sync, shared account, provider permission, data connection, payment route, deployment right, brand affiliation, or custody of an external system.
