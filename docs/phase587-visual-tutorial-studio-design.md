# Phase 587 — Visual Tutorial Studio Design

## Route Audit

The portal already has public, registered learning and discovery routes for **Vibe Canvas**, **August 28 Launch**, **AI Constellation**, **Creator Books**, and the **ScrollVerse Chess Initiative**. The homepage has both top navigation and discovery-card locations for those pathways. `AIConstellationHub` demonstrates the established pattern: source-led tutorial cards, a detailed selected tutorial packet, local brief-copy controls, related registered routes, visible operating states, and a clear distinction between browser-local learning and an external video or provider action.

## Tutorial Taxonomy

The central studio will support two visitor modes. **Start Here** uses short, visual, plain-language cards for visitors encountering ScrollVerse for the first time. **Go Deeper** reveals the supporting source, operating state, practical next route, accessibility preparation, and release boundary for visitors who want more detail.

| Learning lane | First visitor question | Existing route handoff | Operating purpose |
|---|---|---|---|
| Start the portal | What is ScrollVerse and where should I begin? | `/` | Orientation and source-led discovery. |
| Create with evidence | How do I turn an idea into a visible, reviewable plan? | `/vibe-canvas` | Browser-local visual planning. |
| Learn with AI | How do original roles and public AI links fit together? | `/ai-constellation` | Original tutorials and public discovery; no integration implied. |

| Prepare a launch | What records are needed before a creator release? | `/august-28-launch` | Browser-local release planning. |

## Visual System

Each card uses an original, high-contrast visual treatment—numbered orbit, purpose icon, three short steps, a plain-language example, and an operating-state chip. The page uses CSS-driven color fields, grids, layered gradients, and accessible text rather than relying on an unverified video, third-party likeness, or external media asset. Every tutorial has a **Read in 60 seconds** section and a **Short-video brief** section that records what a future original video still needs.

## Short-Video Release Boundary

The browser-local studio can prepare a 30–45 second tutorial script, visual sequence, caption or transcript plan, and route handoff. It does not create a video, clone a voice, upload to Skool, create a course, or imply any public availability. A future video requires an item-specific brief covering purpose, audience, duration, 16:9 or 9:16 aspect ratio, original visual direction, language, narrator decision, music-use authorization, captions, exact Skool destination, and same-conversation owner release.
