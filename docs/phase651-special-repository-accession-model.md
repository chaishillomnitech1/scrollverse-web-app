## Scope

The Special Repository is a browser-local digital archive for ScrollVerse creator records. It preserves source identifiers, evidence state, display state, and future exact release fields without claiming that an asset is filed, tokenized, minted, listed, licensed, sold, or externally stored.

## Evidence Interpretation

The SHA-256 entry identifies the received file bytes at the time of intake. It does not establish authorship, ownership, rights, registration, exclusivity, market value, chain presence, or an external immutable record. The remaining accessions do not receive a file hash because no corresponding external binary was supplied for this repository pass.

## Exact Artifact Release Gate

Before any external repository visibility change, public display expansion, metadata publication, chain action, marketplace action, transfer, or sale, the selected accession requires a current owner release record naming:

> `accession ID`, `representation mode`, `chain and network`, `minting service or contract`, `edition or supply`, `public media decision`, `public custody destination`, `maximum fee`, `artist-recognition or compensation state`, and `marketplace or price decision` where applicable.

No secret, private key, seed phrase, recovery code, private repository location, or custody credential belongs in this browser-local repository.

## Correction Path

New evidence is appended with its source date, visible state, and new identifier. Existing accessions remain readable as their original intake record.
