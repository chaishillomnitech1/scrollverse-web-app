# Phase 634 — Fair Practice Navigator Specification

## Purpose

The Fair Practice Navigator is a browser-local self-review space for creator-controlled catalog work. It helps a visitor organize sources, plain-language release records, correction requests, and next-step questions. It does not decide a legal, financial, provider, platform, rights, royalty, or contract outcome.

## Creator-first review principles

| Principle | Browser-local review question |
|---|---|
| Source clarity | Can the creator point to the cover, release, distributor reference, or source record that supports this entry? |
| Plain-language record | Does the entry state what is available now, what is research, and what requires an owner release? |
| Independent review | Can another person inspect the same public source or local evidence record without needing an account? |
| Correction path | Is there a clear way to flag a title, date, image, credit, or link that needs correction? |
| Exact action boundary | Does the record identify the particular filing, account change, payment, upload, or platform action needed next instead of implying it has happened? |

## Navigator outputs

The navigator may create browser-local copy text and JSON exports containing the selected review answers. It does not submit the review to a distributor, platform, government agency, rights organization, marketplace, or payment provider.

## Connected routes

The Navigator links to **Catalog Stewardship**, **Creator Source + Brand Registry**, **Creator Activation Dossier**, **Replay Readiness**, and **Cover Art Storyworlds**. Each route retains its own records and release state.
