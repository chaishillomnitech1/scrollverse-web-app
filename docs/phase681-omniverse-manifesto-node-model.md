# Phase 681 — Omniverse Manifesto Node Model

## Purpose

Each recovered visible conversation title may be represented as a browser-local **Codex node**. A node is an index record, not a reconstruction of its conversation. It makes the source label navigable while keeping its evidentiary limits visible.

| Field | Meaning | Rule |
| --- | --- | --- |
| `nodeId` | Stable local identifier, `SV-OMNI-001` through `SV-OMNI-051` | Derived from the recovered visible-title ordinal. |
| `sourceTitle` | Exact visible title text | Preserve case and wording from the recovered source. |
| `volume` | Master Index navigation volume | Classification label only; not a statement of conversation subject. |
| `source` | Primary source file and SHA-256 | Links each node back to `Pasted_content_03.txt`. |
| `visibleEvidence` | What is directly known | **Visible title only** unless a separate primary source is attached. |
| `currentState` | Direct operating-state label | **available now** for the browser-local title record; **requires owner release** for transcript expansion or public source attachment. |
| `scopeBoundary` | What the record does not claim | No unseen text, date, author, result, account state, ownership, or verified operating claim. |
| `correctionPath` | How to extend accurately | Add a dated primary source, a title correction, or a separately accessioned record. |

## Node Readiness Gate

A node can expand beyond its title-only state only when an owner-supplied primary transcript, archive export, or separately accessioned evidence record identifies the exact node and its intended display scope. The browser-local node gallery does not retrieve, infer, or connect external accounts.

## Source Boundary

The 51 nodes preserve the title constellation as received. The model does not interpret the wording of a title as a fact, prediction, technical accomplishment, financial status, media release, or proof of underlying chat content.

## Browser Verification

The individual `/omniverse-node/SV-OMNI-027` record rendered the **Immortalize Chats as Book** title, node fields, available-now browser-local state, requires-owner-release expansion gate, correction control, and gallery, Master Index, and chronology handoffs.
