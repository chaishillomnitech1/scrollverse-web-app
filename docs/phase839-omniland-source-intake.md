## Publication Rules

The Omniland page may link to existing first-party ScrollVerse routes and clearly labeled public external sources. It will not claim that a library entry is publicly accessible, embed the reviewed social-media reel, or represent a film, cartoon, game, or release as externally published unless the applicable source and release record is available.
