## Reusable Per-Asset Structure

| Reference field | Reusable local requirement | Boundary retained in the active portal |
| --- | --- | --- |
| Source/version | Give each exact asset a final title/version and a source locator. Use a build hash only when it is relevant and verifiable for that asset. | A pasted version string or claimed commit hash is not evidence of an asset’s final state. |
| Contributor/rights context | Record primary creator, contributors, rights/permission context, and brand/mark review when relevant. | A global name in a template does not replace asset-specific contributor and rights records. |
| Accessible materials | Attach appropriate captions, transcript, alt text, audio description, readable format, and youth guidance where relevant. | A local route prefix alone does not establish accessible source material for a specific asset. |
| Destination | Select one actual destination route, platform, distributor, host, or public network after the asset packet is ready. | A preview destination is not a completed publication or delivery result. |
| Operating state | Continue using **available now**, **research**, and **requires owner release** for creator-facing records. | “Sandbox locked” and “preview stable” can describe preparation context but do not prove public release status. |
| Correction path | Preserve a clear correction record for source, rights, accessibility, metadata, destination, or release outcome. | A future merge script or claimed test number is not itself an operating correction path. |
| Owner release | Record a direct decision for the exact final asset and exact destination. | Broad platform permission does not replace a final asset-and-destination confirmation immediately before an external submission. |

## External Submission Gate

After the action succeeds, attach the actual permalink, delivery confirmation, public-network reference, or store result and a correction path to the asset record.
