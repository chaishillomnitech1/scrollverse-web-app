## Release sequence for any paid item

1. Freeze the **exact edition or service**: title, version, included files or physical components, and customer promise.
2. Attach its **source, rights, and contributor** record; include any credit or split context that is actually documented.
3. Complete **accessibility and delivery**: alt text/captions/transcript or sizing/material information, inventory or digital-delivery model, fulfillment/support path.
4. Set the **specific commercial terms**: price, currency, tax/refund policy, destination URL, and AgapeCycle allocation record if the owner elects to use it.
5. Run a **separate test-mode review** through the selected provider or storefront.
6. Obtain an **action-specific owner confirmation** naming the exact item, destination, price or mechanism, and consequence.
7. Activate only that released item; record the resulting public destination and operating state.

## Shopify storefront-copy activation packet

The current portal cannot bind Shopify because it is already Stripe-configured. The storefront path is therefore a **separate Stripe-free project copy**. The storefront copy must have an approved collection structure, customer-support contact, shipping or digital-delivery policy, tax/refund configuration, item-level release packets, public product URLs, and a tested provider flow before any item is published.

## Safety and privacy boundary

ScrollVerse may link to an approved public external destination. It must never collect passwords, one-time codes, account numbers, card details, wallet seed phrases, private keys, recovery codes, or payout details inside public release notes. A visitor-facing link is not proof that a transfer, payment, payout, license, token issuance, or fulfillment occurred.
