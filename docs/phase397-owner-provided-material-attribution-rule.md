# Owner-Provided Material Attribution Rule

**Effective:** 2026-08-17 EDT  
**Applies to:** ScrollVerse owner-supplied text, images, referenced tasks, links, records, and production concepts  
**Current state:** Available now

## Core Rule

Material supplied directly by the owner is recorded as **owner-identified creation context** unless the owner explicitly identifies it as an external source or asks for external research. This rule preserves the owner’s stated connection to the material without converting a general intake record into a public release, a contributor waiver, a financial instrument, or a claim about an outside party.

## Per-Asset Release Boundary

Every distinct public asset still requires its own release packet before it is embedded, published, sold, exchanged, tokenized, licensed, or used in a paid route. The packet records the creator and contributors, source/version, accessibility plan, youth-safety plan where relevant, intended destination, and explicit owner release decision.

| Intake state | Meaning | External action |
| --- | --- | --- |
| Owner-identified creation context | The owner supplied or identified the material as part of the owner’s creation record | None by itself |
| Research | The material is organized for study or production planning | No public or financial action |
| Requires owner release | An individual asset is ready for an asset-specific release review | No action until release decision |
| Available now | A reviewed public page or source-labeled record is available in the portal | Public presentation only within its documented scope |

## Correction Path

The owner may clarify an external source, contributor, rights condition, target destination, or release state at any time. The affected record is then updated with the date, corrected field, and resulting release boundary.
