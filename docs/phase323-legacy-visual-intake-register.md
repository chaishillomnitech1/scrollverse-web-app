## Initial Rights and Remembrance Boundary

The visual batch is not treated as evidence that any team, athlete, public figure, brand, marketplace, QR destination, product, or external platform has authorized public use. The sports-themed images can guide a **new original basketball-city world** built around distinct characters, uniforms, symbols, phrases, and color systems rather than third-party teams, players, celebrity fans, or near-lookalikes.

The Harlem–Vineland material will be presented as the owner’s personal archival observation. Its source fields can record the stated context—Harlem birth history, a 7:00 p.m. time reference, an 8:28/78° screenshot observation, and Vineland location context—without representing the display as externally verified proof of causation.

## Accessibility Direction

Every selected visual will receive concise alt text that identifies the visible subject, composition, and any essential on-screen time/location text. Mobile screenshots require a transcript of visible text where it matters to the archival record. QR-containing art needs a verified destination or a description that it is decorative; it should not be presented as a working code until tested.
