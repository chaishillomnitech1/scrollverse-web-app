# Owner-Controlled Release and Deployment Handoff

## Completed First-Party Work

The ScrollVerse portal is live, source-labeled, versioned, and covered by route and regression checks. Its public readiness routes, creator systems catalog, media/portfolio navigator, protected evidence records, and fail-closed digital-asset learning surfaces are complete as first-party work. They do not require a private session, a wallet, or an external provider to remain accessible.

## Remaining Owner-Controlled Steps

| Gate | What the owner controls | What remains intentionally inactive |
|---|---|---|
| Private release record | Authenticated access to the applicable release workspace. | No attempt to reuse, bypass, or simulate a private session. |
| App icon and provenance | A cleared original icon file and an existing provenance record selected by the owner. | No public use, upload, or administrator assignment based on an unreviewed asset. |
| Administrator assignment | Selection of the real account/administrator in the private release workspace. | No guessed identity, fabricated administrator, or unverified provenance linkage. |
| Mainnet deployment | A fresh credential stored only in the authorized secret field, verified contract set, budget/network review, and an explicit broadcast-time confirmation. | No wallet connection, credential handling, broadcast, contract deployment, transaction, or portal contract linkage. |
| Confirmed contract addresses | Independently verifiable public addresses after a confirmed broadcast. | No display of unverified addresses as active contracts or use in token, mint, or payment functions. |

## Safe Handoff Sequence

The owner can first provide the cleared non-sensitive icon file and identify the provenance record to use. Once the authenticated release workspace is available, the owner can assign the actual administrator and review the private record. Mainnet work is separate: it begins only after the owner has securely set a **fresh** credential in the authorized secret field and provides an explicit instruction confirming the exact verified contract set, target network, and intent to broadcast at that time.

> The prior credential disclosed in conversation is permanently disqualified. It must not be copied, stored, reused, or supplied again.

## Completion Feedback

After any owner-controlled step is completed, ScrollVerse can record only its observable outcome: a verified private-record status, a cleared asset reference, or publicly verifiable contract evidence. It will not publish private account data, credentials, balances, transaction data, or restricted provenance records.
