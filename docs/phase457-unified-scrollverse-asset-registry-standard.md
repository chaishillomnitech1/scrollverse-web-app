# Phase 457 — Unified ScrollVerse Asset Registry Standard

**Purpose:** Extend the evidence-first museum method across all ScrollVerse asset types so each original creation, owner-held object, source record, and future collector concept has a stable identity, source trail, rights state, visitor pathway, and release gate.

## Registry principle

The registry makes the owner’s creative universe navigable without pretending that every asset has the same rights, release status, price, or public destination. Each item retains its own record. A visitor can explore the source, read the operating state, and choose a valid available pathway.

> **One registry, many asset types; one item, one source trail; one release, one exact action record.**

## Asset taxonomy and stable IDs

| Asset family | Stable ID example | Primary record |
| --- | --- | --- |
| Owner-held physical artwork | `SV-PHYS-ART-001` | Accession, evidence, condition, attribution, custody, and display state |
| Owner-created digital artwork | `SV-DIGI-ART-001` | Source file, version, creator context, rights, and public-display state |
| Music and sound | `SV-MUSIC-001` | Master/source context, contributor release, distribution state, and visitor destinations |
| Books and lessons | `SV-BOOK-001` | Manuscript, source trail, accessibility, edition, and reader-release record |
| Visual media | `SV-VIS-001` | Footage/source, contributor, edit/version, rights, and public destination |
| Software and systems | `SV-SYS-001` | Repository/source, license, deployment state, documentation, and support boundary |
| Research and archive record | `SV-RESEARCH-001` | Source organization, date/context, access label, scope, and correction path |
| Collector concept | `SV-COLLECTOR-001` | Source asset, representation mode, rights state, metadata, and mint readiness |
| Community or service concept | `SV-SERVICE-001` | Original scope, delivery definition, terms readiness, and owner release |

## Minimum item record

| Field | Requirement |
| --- | --- |
| Registry ID | Stable item identifier that is never reused |
| Asset family | One primary taxonomy category; optional cross-links to related records |
| Owner and source context | Owner-authored statement, original source file, acquisition context, or public-source provenance |
| Visible or confirmed attributes | Only what the record supports; label partial/transcribed information clearly |
| Rights state | Owner-original, owner-held physical, licensed, public-domain/open, third-party research, or not established |
| Public-display state | Collection record available, public release approved, research, or requires owner release |
| Visitor-choice path | Free reading/viewing, external public source, approved catalog path, proposal route, or no public destination yet |
| Commercial pathway | Not applicable, research only, release-gated paid edition, release-gated collector representation, or release-gated service scope |
| Correction path | Dated source correction and current operating state |

## Commercial-pathway model

The registry does not turn the catalog into a blanket storefront. A commercial pathway is a specific item-level record.

| Asset state | Visitor can do now | Requires a separate named record |
| --- | --- | --- |
| **Free exploration** | Read an original source card, visit an external source, use a browser-local prompt, or view an approved collection description | Any paid edition, license, public artwork image, provider connection, or payment destination |
| **Research** | Inspect the source, limitation, and correction path | Public claim, item sale, collector offer, price, or release statement |
| **Requires owner release** | Read the planned pathway and preparation criteria | Listing, payment, mint, token, delivery, creator compensation, or promotional activity |
| **Release-gated paid edition** | Understand the item’s planned type and terms requirements | Exact price, currency, payment destination, delivery, support, terms, and owner confirmation |
| **Release-gated collector representation** | Review provenance and representation design | Public media, rights holder approval, chain/network, custody destination, fee cap, edition, mint, listing, or transfer |

## Registry connections

The Art Museum, Art Learning Studio, Knowledge Commons, Perspectives Imprint, Catalog Production Desk, Product Release Pipeline, Activation Register, Payment Options Map, and Delivery Resilience routes are connected registry lenses. They show different stages of the same item journey but do not replace the item’s own source, rights, and release record.

## Local intake

The registry can prepare a new item locally with type, title, source summary, rights state, intended visitor path, and next evidence needed. Preparation is browser-local until the owner chooses a specific database, public page, provider, publication, commercial, or transaction action.
