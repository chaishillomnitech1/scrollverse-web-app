## Integrity reference

NIST defines a hash value as a string of numerical values used to substantiate digital-evidence integrity. Its Secure Hash Standard says hash digests can be used to detect whether messages have changed since generation. The Artifact Evidence Blueprint uses this narrow integrity concept and does not expand it into an ownership, identity, rights, permanence, or blockchain claim. [1] [2]
