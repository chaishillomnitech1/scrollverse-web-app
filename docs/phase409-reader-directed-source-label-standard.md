# Phase 409 — Reader-Directed Source-Label Standard

## Purpose

This standard applies to owner-supplied promotions, videos, channels, shared files, transcripts, screenshots, and external links presented in ScrollVerse research or learning routes. It keeps a creator or source’s own framing visible while allowing visitors to see what is directly accessible, what remains an attributed claim, and where a correction or supporting source can be added.

## Required fields

| Field | Record requirement |
| --- | --- |
| Source identity | Title, creator or channel where visible, URL, source type, and access date |
| Source framing | A concise description of what the source presents itself as saying or exploring |
| Claim status | Mark as source-stated, independently supported, unresolved, or corrected; never collapse the categories |
| Supporting source | Link primary, official, or directly accessible material when a factual claim is discussed |
| Operating state | Use available now, research, or requires owner release for the ScrollVerse route and linked artifact |
| Accessibility | Include a text summary, visible source link, and transcript or caption status when accessible; avoid reproducing a video’s full expression without permission |
| Rights and purpose | State that embedded media, creator identity, brand, likeness, or full reproduction needs a purpose-specific rights record; use links and original summaries by default |
| Correction path | Link the Co-Creation Navigator for sources, dates, identity corrections, additional context, or directly accessible counterevidence |

## Presentation boundary

The record can preserve a source’s perspective, including an alternative or unconventional interpretation, without recommending it, amplifying it as a conclusion, or treating it as verified. A linked channel is an access path, not a partnership, endorsement, distribution arrangement, or statement that ScrollVerse agrees with every video.

## Visitor choice

The visitor can open the source, read the summary and source labels, inspect any supporting material, add a correction, or leave the conclusion open. No record creates an automated subscription, social action, booking, payment, account connection, financial decision, or external publication.
