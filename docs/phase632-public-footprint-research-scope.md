# Phase 632 — Public Music + Media Footprint Research Scope

## Research identifiers

The public footprint review uses the supplied identifiers **Chais the Great**, **#chaisthegreat**, **#XLVIIIblocks**, and **ScrollVerse.co**. Results are classified individually; a name, hashtag, or visual resemblance alone does not identify an account or release as the creator’s record.

## Source hierarchy

| Priority | Source track | Evidence accepted into the public record |
|---|---|---|
| 1 | Owner-supplied direct profile, release, or smart-link URL | Public URL and the platform’s visible metadata. |
| 2 | Platform-hosted public profile or release page | Visible profile name, title, provider, cover, and canonical URL. |
| 3 | Official public embed or metadata endpoint | Returned title, provider, image, and canonical item identifier. |
| 4 | Search-indexed public result | Platform and title only after the linked page is opened or otherwise verified. |
| 5 | Owner-supplied textual context | Source record or discovery lead; never treated as a verified public platform state on its own. |

## Platform tracks

The review begins with **Spotify**, **Apple Music**, **YouTube**, **Vyd.co**, and public web results that connect the supplied identifiers to a visible source. It may record other public DSP or media services only when a link, platform name, and visible catalog context are independently present.

## Classification

| State | Meaning |
|---|---|
| `CONFIRMED PUBLIC RECORD` | Public profile, release, cover, or smart link is visible through a supported source trail. |
| `OWNER-SUPPLIED DISCOVERY LEAD` | Owner-provided link or catalog statement awaits public metadata or visual verification. |
| `AMBIGUOUS / DO NOT ASSIGN` | A public result cannot be connected to the supplied creator identifier without guessing. |

Every published record will show its source, platform, retrieval date, visible metadata, and a correction pathway. The review will not attempt sign-in, private dashboards, paid accounts, distribution uploads, royalties, playlist pitching, media publishing, or changes to any platform account.
