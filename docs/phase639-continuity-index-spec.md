# Phase 639 — ScrollVerse Continuity Index Specification

## Purpose

The Continuity Index is a browser-local control surface that joins the active workspace’s source intake, published portal milestones, creator catalog systems, research records, safeguards, and exact external release gates. It is a navigational and exportable record, not a background coordinator or a substitute for a provider account.

## Record types

| Record type | Browser-local purpose | Connected routes | Boundary |
|---|---|---|---|
| Source intake | Tracks owner-supplied files, links, screenshots, and protected reference packets. | Creator Source + Brand Registry, Cover Art Storyworlds | It records available context; it does not publish or redistribute source files. |
| Creator catalog | Joins releases, cover records, story directions, and local stewardship fields. | Cover Art Storyworlds, Catalog Stewardship, Public Footprint | It does not access distributor accounts, report royalties, or initiate distribution. |
| Evidence and safeguards | Connects source trails, public references, local corrections, and access boundaries. | Digital Intelligence Safeguards, Sovereign Isolation Terminal, Research Atlas | It does not establish external enforcement, registration, or legal effect. |
| Continuity and handoff | Preserves active task context, memory snapshots, corrections, and protected-archive preparation. | Legion Continuity Lab, Creator Activation Dossier | It does not run unattended jobs or create a repository. |
| Exact external gate | Maintains required fields for an unblocked provider, wallet, media, DNS, or store action. | Creator Activation Dossier, Replay Readiness | It never converts a gate into an active action without the exact item record. |

## Session-source boundary

The current workspace can index the source materials and records already available to it. Other Manus sessions require an owner-attached session reference or shared link. When attached, their visible conversation and exported artifacts are treated as separate source families; no unrelated, private, or unavailable chat is assumed to be accessible.

## Local controls

The first release includes record filtering, record detail selection, local summary copy, and local JSON export. It does not synchronize, publish, send, schedule, upload, modify an external account, or create a remote repository.
