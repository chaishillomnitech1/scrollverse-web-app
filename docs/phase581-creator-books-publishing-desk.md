# Phase 581 — Creator Books Publishing Desk

> بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ

**Purpose:** Provide a browser-local command desk that turns an owner-authored book idea or manuscript into a visible, source-led release record.  
**Operating state:** **browser-local publishing planning**.

| Publishing layer | Available now | Exact input needed for release |
|---|---|---|
| Working-title catalog | Source-labeled title cards and direct operating-state labels | Author-confirmed title, intended public description, and source/date |
| Manuscript record | Browser-local manuscript/source and author/contributor checklist | Cleared manuscript or approved excerpt and rights/contributor record |
| Reading edition | EPUB/PDF/print planning fields and accessibility checklist | Final approved file, reading order, alt text, semantic structure, and destination |
| Visual edition | Cover and visual-companion planning fields | Original/cleared visual assets, purpose, display rights, and accessibility descriptions |
| Voice edition | Narration and audio-book production record | Original narration direction, voice authorization, script, captions/transcript, music-use record, and destination |
| Distribution | Destination and customer-terms record | Named distribution provider/retailer, account owner, terms/privacy/cost review, and explicit owner release |

## Direct operating-state standard

The desk uses **available now**, **research**, and **requires owner release** labels. It treats working titles and source records as creative planning, not publication. A title becomes a public release only after the exact manuscript, rights, accessibility, edition, destination, and owner-release fields are complete.

## Publisher boundary

The desk does not upload manuscripts, create retail accounts, generate an ISBN, create a cover, synthesize narration, distribute an ebook or audiobook, set a price, collect payment, or claim a book is live. It creates the transparent record that makes each of those actions easier to do correctly when the owner supplies the item-specific information.
