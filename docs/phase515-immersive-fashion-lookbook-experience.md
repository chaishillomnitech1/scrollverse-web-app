## Experience structure

The immersive fashion lookbook experience joins three source-labeled original fashion lanes: **MEIN Fusion**, **XLVIII BLOCKS**, and **#XLVblocks Atlantis**. Visitors can select a world, inspect a stage visual, change a local viewing mood, select a silhouette, and prepare a browser-local visual brief. The visual references used on the stage remain explicitly labeled as owner-provided display references or concept-only fashion studies.

| Element | Available interaction | Current operating state |
|---|---|---|
| Look-world selector | Switches local MEIN, XLVIII BLOCKS, and Atlantis records | Available now in browser; no preference record is saved |
| Viewing mood | Ambient drift, focus glow, or reduced-motion still frame | Local visual display only |
| Silhouette selector | Changes the selected concept lane in the current session | No item, bag, reserve, sample, offer, or listing is created |
| Visual brief control | Presents a local confirmation message | No media generation, provider, commerce, or release action |

## Visual-to-release boundary

The page distinguishes a concept, display reference, approved image, production record, campaign, product, and checkout state. A future public release must carry its own source, rights, accessibility, selected use, production, delivery, customer terms, provider configuration, and exact owner authorization. The route does not create a garment, vendor order, product record, inventory, price, license, campaign, media player, listing, checkout, payment, token, wallet action, or publication.
