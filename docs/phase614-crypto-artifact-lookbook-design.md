# Phase 614 — Crypto Artifact Lookbook and Cross-Promotion

## Purpose

The Crypto Artifact Lookbook is a browser-local discovery route for the creator’s visible crypto-adjacent artwork, AI artifact visuals, source records, and preparation pathways. It connects visual worlds to the systems that explain, preserve, and prepare them without representing a visual label, icon, coin image, chart, or collectible treatment as a live financial or token operation.

## Discovery structure

| Lens | What visitors can see | Connected route | Operating label |
|---|---|---|---|
| Artifact evidence | How a physical or digital object receives a source, accessibility, and release record | `/artifact-evidence-blueprint` | Available now |
| Visual artifacts | Browser-local visual accessions and creator-world treatments | `/evolution-lookbook` | Available now |
| Creator collection | Physical, digital, fashion, and visual collection records | `/creator-collection-records` | Available now |
| Crypto systems | Educational system layers and readiness material | `/crypto-systems-atlas` | Research and preparation |
| Activation review | Exact-record handoffs for external release lanes | `/activation-dossier` | Requires owner record |
| Cross-world discovery | Connected visual, media, learning, book, and creator systems | `/creator-atlas` | Available now |

## Artifact card vocabulary

Each card is tagged with an **artifact type**, a **source basis**, and an **operating state**. The four intended states are `Artwork record`, `Source record`, `Preparation pathway`, and `Requires exact release record`.

Visible coin names, yield charts, NFT labels, wallet imagery, token illustrations, or contract metaphors are treated as part of visual artwork or source material unless an independent, item-specific release record provides the exact external information for a different operating state.

## Cross-promotion behavior

The lookbook provides direct internal handoffs among existing ScrollVerse routes. It does not post to another site, connect a wallet, request a signature, list an item, create a token, discover a price, execute a trade, conduct a sale, or call an external provider. The visitor chooses the next browser-local route.

## Correction path

If the creator identifies a wrong source label, route, artifact type, accessibility description, or operating state, the correction is recorded in the relevant source evidence document before changing the public card. Any external release state needs the matching exact owner-controlled record in the Activation Dossier.
