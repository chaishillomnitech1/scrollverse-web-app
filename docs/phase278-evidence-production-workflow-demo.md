# ScrollVerse Evidence-First Production Workflow — Demonstration Guide

> **Purpose:** This guide demonstrates how the reusable workflow turns an ambitious creative or technical reference into an original, evidence-labeled project record. Every example remains **research** or **requires owner release**. Nothing here is a public release, live integration, legal clearance, medical claim, wallet action, provider activation, or production deployment.

## The Workflow in One Screen

| Step | Question answered | Evidence created |
|---|---|---|
| 1. Intake | What was received and what is it intended to become? | Source log and operating state |
| 2. Separation | What is owner-stated, publicly accessible, original, or still unverified? | Source boundary |
| 3. Original work | What new creative or technical work can be made without copying or assuming rights? | Script, cue sheet, album brief, review form, or architecture note |
| 4. Readiness | What is missing before a visitor can encounter it as available work? | Rights, credit, accessibility, safety, and owner-release gate |
| 5. Presentation | What may the portal show honestly today? | Direct operating-state label and correction path |

## Example 1 — Episode Scene and Composer Cue

### Intake

| Field | Demonstration record |
|---|---|
| Working title | *The Black Beacon Chronicles: Signal at Harbor Nine* |
| Source | Owner-supplied planning reference describing a night-time cyber-thriller episode and score concepts |
| Reusable lesson | Establish tension through a shared public problem, distinct team roles, and a responsible, human-scale resolution |
| Originality decision | Use a distinct project title, setting, and character language; do not represent it as a DC Comics work or an authorized use of another character identity |
| Current state | **Research** |

### Original 90-Second Scene Excerpt

**EXT. HARBOR NINE — NIGHT**

Rain cuts silver lines through the loading cranes. **MARA VOSS**, a neighborhood archivist, holds a damaged radio receiver beneath a canopy. Across the pier, the city’s public-alert display is repeating the same ten seconds of emergency text.

**MARA**

> “It is not asking for a savior. It is asking for someone to listen.”

**ION KEST**, a systems cartographer, kneels beside a portable signal case. He does not touch the broadcast. Instead, he isolates a copy for review.

**ION**

> “We preserve the evidence first. Then the people decide what belongs in the record.”

The display settles. A new line appears: **SOURCE UNKNOWN — CORRECTION CHANNEL OPEN**.

### Cue 01 — “Harbor Signal”

| Time | Musical direction | Accessibility and mix notes |
|---|---|---|
| 00:00–00:22 | 76 BPM, D minor, brushed low drum and muted electric piano | Keep dialogue range clear; no sudden impact above dialogue bed |
| 00:22–00:48 | Add bowed-bass pulse and distant harbor-bell texture | Describe the flashing public display in captions; avoid rapid strobe visuals |
| 00:48–01:20 | Resolve to open D sus2 voicing with a single choir-like synth pad | Create a text cue sheet and audio-description timing note |
| Delivery target | Versioned stereo mix and stems | Confirm final loudness and true-peak target after the actual master is mixed |

### Release Gate

This scene becomes **requires owner release** only after final title approval, script author credit, performer agreements if recorded, original-score confirmation, visual source record, captions/transcript, audio-description plan, age-appropriate review, and the owner’s chosen destination are all documented.

## Example 2 — ScrollStorm Single Packet

### Intake and Production Brief

| Field | Demonstration record |
|---|---|
| Working single | *Room to Breathe* |
| Creative objective | A reflective late-night record about making room for evidence, memory, and community repair |
| Source inspiration | Owner-supplied album-matrix reference; no claim that an album master, release, DSP delivery, royalty engine, or label campaign exists |
| Current state | **Research** |

### Original Arrangement Card

| Section | Tempo / key | Arrangement | Lyric or vocal direction |
|---|---|---|---|
| Intro | 84 BPM / F-sharp minor | Felt piano, room tone, low analog bass | Spoken breath count, close-mic and conversational |
| Verse | 84 BPM / F-sharp minor | Kick enters after four bars; dry rim clicks | “Leave a little room / for the truth to arrive” |
| Chorus | 84 BPM / A major lift | Warm pad, stacked third harmony, restrained guitar | “We make room to breathe / and a path to be believed” |
| Bridge | Half-time feel | Drop percussion; piano and lead vocal only | Credit all writers and performers before any recording |
| Outro | 84 BPM / F-sharp minor | Return to intro texture; no abrupt hard stop | Spoken correction path: “If the record needs a change, leave it in the light.” |

### Mini Evidence Packet

| Requirement | Demonstration status | Needed before release |
|---|---|---|
| Songwriter/composer identities | Not recorded | Written split and credit confirmation |
| Vocal/master source | Not recorded | Final master, mix version, stems, and mastering record |
| Artwork | Not selected | Source, artist permission, alt text, and promotional crop approvals |
| Lyrics and accessibility | Draft excerpt only | Final lyric sheet, synchronized captions, and content-sensitivity review |
| Destination and commercial terms | Not selected | Explicit owner release and destination-specific metadata |

> **Skill behavior:** The workflow allows a compelling music plan today while preventing a plan from being misrepresented as a released record, trackable royalty flow, or live DSP placement.

## Example 3 — Contributor Visual Intake

### Submission Scenario

A contributor proposes a 30-second animated harbor visual for the episode’s title card. They provide a file, a title, and a social handle but no evidence packet.

| Review field | Example answer | Result |
|---|---|---|
| Source location | Contributor-provided file path is recorded | Continue intake |
| Intended use | Episode title card and promo excerpt | Continue intake |
| Rights statement | “I made it” without signed scope or asset-source notes | **Hold** |
| Artwork/footage source | Unclear whether source images, stock, AI generation, or third-party marks are involved | **Hold** |
| Accessibility | No alt text, captions, flash-sensitivity notes, or visual description | **Hold** |
| Youth safety | No age-appropriateness review | **Hold** |
| Current state | **Requires owner release** | Do not embed or publish |

### Workflow Output

The portal may show a browser-local review card such as: **“Contributor visual — evidence requested.”** It may not show a public player, a licensing claim, a creator payment promise, or an approved-credit line until the contributor completes the per-asset evidence packet.

## Example 4 — Technical Blueprint, Not a Deployment Claim

### Request

An owner-supplied document says a media platform, contract, database, routes, and post-quantum controls are “online and locked.” The skill treats this as a **protected technical reference**, not as a verified implementation.

| Planning lane | Honest documentation action | Disallowed shortcut |
|---|---|---|
| Media library | Draft a content model for asset, packet, contributor, master, and release decision | State that a public streaming platform is already live |
| Security | Record a research lane for threat model, key management, migration assessment, and review | Claim cryptographic controls are compiled, active, or auditable without verification |
| Database | Draft fields and retention/access rules appropriate to the current project stack | Paste an unrelated schema or run a migration without schema review |
| Smart contracts | Preserve a contract idea in an architecture note | Compile, deploy, connect a wallet, mint, or treat a copied address as live |
| Automation | Identify a future owner-approved job with its input, output, audit trail, and kill switch | Start a background process or provider integration from an attachment |

### Demonstration Architecture Note

```text
ProductionAsset
  ├── source_record
  ├── rights_packet
  ├── accessibility_packet
  ├── contributor_credits
  ├── release_decision
  └── correction_history

ReleaseDecision
  ├── destination
  ├── owner_approval
  ├── available_state
  └── published_at (empty until released)
```

This is a data-model concept only. It is not a migration, deployed database, provider connection, contract, blockchain record, or public release service.

## Demo Result: What the Skill Changes

| Before the workflow | With the workflow |
|---|---|
| A pasted production manifesto is described as complete and live | Its useful creative and technical lessons are retained, while availability remains evidence-based |
| A strong title is assumed cleared for public use | A distinct original title is drafted pending evidence and release decisions |
| A music plan is mistaken for a launch | The plan becomes a searchable, credit-ready pre-production packet |
| A contributor file is treated as usable because it exists | It receives a transparent evidence request and a correction path |
| A technical blueprint is conflated with deployed infrastructure | It becomes a safe research and architecture record |
