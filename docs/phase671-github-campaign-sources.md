## Boundary

The Campaign Activation Center prepares, copies, and exports browser-local briefs. It does not post, advertise, purchase media, send outreach, change repository visibility, update a store, or create a provider campaign. Each external step requires the named destination, exact intended-use scope, visibility, and final owner release decision.
