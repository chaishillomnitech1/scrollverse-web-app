# Phase 353 — Guardian & Participant Identity Pattern

**Operating state:** authenticated participant and public-profile controls; identity, visibility, authorship, and interaction preferences remain participant-controlled.

| Control | Pattern |
|---|---|
| Identity | Guardian profile handle supports a public-facing identity; community exchange supports author-selected display name or pseudonym |
| Visibility | Participant selects public, community, or pseudonymous profile visibility where available |
| Authorship | Entries and replies display the author-selected name; participant content remains distinct from portal source records |
| Reply and reaction | An author chooses whether replies are allowed; authenticated participants choose reactions and saved reflections |
| Correction | Participant settings and first-party source/correction paths provide the local correction route |

The pattern does not establish that a profile, entry, reply, reaction, or saved reflection is a verified external identity, endorsement, professional conclusion, or provider action. It preserves participant control within the authenticated portal environment.
