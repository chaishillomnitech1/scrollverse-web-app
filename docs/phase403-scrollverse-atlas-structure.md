# Phase 403 — ScrollVerse Atlas Structure and Protected Cross-Link Boundary

**Status:** local route architecture; public release remains dependent on managed checkpoint reconciliation.

## Purpose

The **ScrollVerse Atlas** is a highlighted, reader-directed map of the portal. It is designed to make the work reachable from one place without presenting a list of links as a claim about an external outcome. Each atlas lane names its source context, its current operating state, and the connected routes where a visitor can encounter the work directly.

## Reader-directed standard

The Atlas shows **owner-authored record**, **local project record**, and **external or future state** as separate visible categories. Visitors are invited to follow a route, compare a source, add a correction, or return later. The Atlas does not require acceptance of an interpretation and does not convert a local route, a pasted reference, or a future release idea into an external outcome.

## Protected cross-link boundary

The supplied cross-link material is retained as protected, non-executable input. The Atlas may provide its own locally registered routes and the separately owner-provided Sovereign Hub destination. It does not import external scripts, media, catalogs, provider configurations, catalog counts, royalty terms, token or wallet states, contract labels, test totals, or deployment claims from supplied material.

## Correction and release path

Visitors can use the existing co-creation route to submit a source or correction. Any media, financial, token, provider, wallet, contract, payout, or marketplace release continues to require its own original asset, rights and contributor record, accessible presentation plan, intended destination, and explicit owner release decision.
