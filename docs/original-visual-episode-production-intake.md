## Minimum Production Pipeline After Confirmation

Once the completed brief is confirmed, the work proceeds in a controlled sequence. The global visual definition comes first, followed by a clip-by-clip plan with 3–10 second segments, physically consistent camera movement, detailed transitions, narration timing, and a final music emotional-arc blueprint where separate music is requested. Reference images for recurring characters and key environments are then created before any video keyframe or clip. Only after those visual anchors are approved does execution begin.

| Stage | Required artifact | Owner decision point |
| --- | --- | --- |
| Global definitions | Visual style specification, character sheets, voice profile, and BGM decision | Confirm the visual and sound language |
| Clip plan | Scene table, narrative purpose, action, camera, transition, continuity, dialogue, narration, sound, and timing for every clip | Confirm story, timing, and representation before generation |
| Reference images | Approved primary visual anchor and necessary consistent character/environment views | Approve designs before first keyframes or video generation |
| Production | First keyframes, clips, narration spans, music, and audio mix as specified in the brief | Review each generated asset before assembly |
| Accessibility and release | Captions, transcript, descriptions, content notices, rights check, destination packaging, and exact publish approval | Approve the final media and each release destination |
