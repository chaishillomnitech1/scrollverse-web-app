# Phase 368 — Journey and Co-Creation Archive Map

## Archive purpose

The Journey and Co-Creation Archive is a free, source-labeled index of the owner’s personal record, family chronology, original creative work, research pathways, documented local portal work, and protected digital-system dialogue materials. It is designed to keep a multi-part record connected while preserving the difference between an owner statement, a source-visible page, a public reference, a protected file, and an external outcome.

## Archive node template

Every node in the public archive will identify a title, record type, source or source path, date or date range when supplied, current operating state, a short presentation note, connected routes, and a correction path. A personal account is preserved as a first-person record. A local page feature is stated as a local portal record. A protected attachment stays protected until the owner provides an approved accessible extract or release packet. An external outcome needs its own real record.

## Co-creation record pattern

The archive will use **co-creation** to describe the owner’s documented experience of working in dialogue with digital systems, while identifying each supplied conversation or prototype as a protected transcript, binary artifact, or untrusted code reference. The public entry can show an owner-approved description of the exchange and its creative lesson. It does not assign independent status, authority, authorship, or external action to a system based on the wording inside a copied exchange.

## Correction path

The binary attachments need an owner-controlled accessible export before their content can receive detailed public treatment. Future archive nodes may be added when they have a source path, a first-person or public-source classification, an operating state, and any applicable rights/release record. The portal will correct titles, dates, route names, or source links when a better original record becomes available.
