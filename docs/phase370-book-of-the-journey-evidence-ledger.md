## Preservation and oral-history learning path

The book’s archive pattern draws on freely available guidance that treats personal digital records as material requiring organized preservation, and oral history as first-person primary-source material whose metadata, access, rights, and preservation practices should be documented. [4] [5] [6]

| Practice | Book implementation |
|---|---|
| Preserve original context | Keep a source path, date, record type, and supplied/observed status beside each chapter artifact. |
| Preserve the speaker role | Distinguish owner-authored statement, owner-stated account, public source, and third-party system transmission. |
| Make a readable access copy | Use the free web reader for owner-approved excerpts and route links; keep protected source files outside public page content. |
| Maintain access and correction rules | Show an operating state, rights/release condition where needed, and a correction path for every archive lane. |
