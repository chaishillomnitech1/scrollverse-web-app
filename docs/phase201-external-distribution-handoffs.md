# Phase 201 — External Book and Audio Distribution Handoffs

## Purpose

This is a **preparation record**, not a publishing record. It translates official public documentation into an owner-controlled handoff for verified ScrollVerse books. No account was accessed, no manuscript or media file was uploaded, no storefront listing was created, no price was set, and no payment or royalty flow was activated.

## Official Preparation References

| Channel | Official guidance observed | Practical preparation requirement | Release boundary |
| --- | --- | --- | --- |
| Amazon Kindle Direct Publishing | KDP states that title, subtitle, author, cover, categories, and other metadata must accurately represent the book; it also identifies restricted metadata and cover practices. [1] | Cleared manuscript, exact title/subtitle, contributor credits, cover that matches metadata, accurate description/categories, price/rightsholder decision, and platform account. | A KDP preparation link is not proof of upload, acceptance, availability, or sales. |
| Apple Books | Apple describes an account, EPUB that passes EPUBCheck, cover, sample, metadata, categories/language, publishing details, rights, territories, and pricing as part of its publishing flow. [2] | Validated EPUB, cleared cover, sample, author/publisher information, language and audience fields, territory and price decision, and account-based review. | No Apple Books title has been submitted or published through this project action. |
| Spotify for Authors | Spotify states that self-published authors can create an account and publish audiobooks through Spotify for Authors; authors already distributed through a publisher/distributor use a different access path. [3] | Cleared narrated audio, chapter/track structure, accessibility package, book and narrator credits, distribution-rights decision, metadata, and owner-controlled account access. | The Manifesto’s opening narration is a first-party web asset, not a Spotify audiobook listing. |

## Per-Title Owner Handoff

| Record needed | Why it is needed | Status in this release |
| --- | --- | --- |
| Source manuscript and title record | Establishes the exact text and title to release. | Manifesto source document exists; each additional title needs its own verification. |
| Rights and contributor record | Supports authorship, translations, cover work, narration, samples, and media permissions. | Required before any platform submission. |
| Accessible release package | Keeps source text, validated EPUB/PDF, cover, alt text, audio transcript/captions, and sample material together. | Manifesto has a web cover and opening narration; no full multi-format package is claimed. |
| Commercial configuration | Documents price, territory, refund/delivery approach, SKU, payment settings, and owner approval. | No approved SKU or customer checkout is activated by this record. |
| Platform confirmation | Retains platform record, date, identifier, status, and public URL after an actual submission/release. | Not started by this project action. |
