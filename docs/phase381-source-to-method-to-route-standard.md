# Phase 381 — Source-to-Method-to-Route Standard

**Operating state:** a reusable documentation method; no research item becomes a portal claim or external action without route-specific evidence.

| Stage | Required record | Output boundary |
|---|---|---|
| Source | URL/file, date, author/publisher where known, classification, allowed use | Preserve source; do not reproduce protected material beyond a compatible reference |
| Method | Useful lesson, limitation, counter-evidence question, accessibility need, correction path | Do not convert an observation into a fact, endorsement, or professional conclusion |
| Route | Named portal page, visitor benefit, operating state, owner/release gate, regression test | Do not activate a provider, account, checkout, wallet, token, schedule, post, or publication |

Every route improvement carries a source label, factual state, limitation, correction path, and testable local change. Source material, research, local capability, owner release, and independently verified external outcomes remain distinct.
