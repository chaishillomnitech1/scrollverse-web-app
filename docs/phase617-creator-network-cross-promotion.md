# Phase 617 — Creator Network Cross-Promotion

## Purpose

The Creator Network makes the existing ScrollVerse body of work easier to traverse as one connected system. It gives every visitor a simple starting choice, then hands them to registered browser-local routes rather than describing an unlinked destination.

## Network taxonomy

| Network lane | Visitor purpose | Connected routes |
|---|---|---|
| Visual archive | Encounter artwork, apparel records, and artifact concepts | Evolution Lookbook, Crypto Artifact Lookbook, Creator Collection Records |
| Apps and systems | Explore browser-local workspaces and systems maps | Connected Systems, Creator Workspace, Vibe Canvas |
| Learning and books | Find learning paths, creator books, and open knowledge | Visual Tutorial Studio, Creator Books, Open Knowledge Verse |
| Media and broadcast | Prepare narrative, broadcast, and visual treatment work | Creator Broadcast Preparation, Creator Media Packet, Visual Story Worlds |
| Collaboration and readiness | Review evidence, participation, and exact next-record preparation | Collaborate, Activation Dossier, Capability Comparison |

## Cross-promotion rules

Every network card must name a registered route, state its current browser-local function, and offer an explicit next link. The network does not imply external platform integration, availability of a product, live token state, marketplace activity, or partner participation.

## Correction path

If a route changes, update the card label, description, and destination together. If an item moves from preparation to an active external state, record that transition in its own source and release record rather than changing a cross-promotion card alone.
