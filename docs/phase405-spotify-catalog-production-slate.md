## Shared production standard

Each item requires a clean master reference; final title and version; composition, master, artwork, footage, performer, sample, likeness, mark, and contributor records; caption, transcript, lyric-sheet, audio-description, alt-text, sound/flash sensitivity, and youth-safety plan where relevant; an approved publication destination; a free/paid decision; and an explicit owner release decision. The storyboards will use original characters, original environments, and original visual language unless purpose-specific permissions exist.
