## Provider Boundary

The register makes no Shopify, GitHub, Manus, Meta, payment, token, wallet, repository, domain, or publication change. It does not expose credentials, private store content, customer information, payment settings, private repositories, or account sessions.

## Correction Path

The owner can add a direct public URL, dated source capture, approved destination, or item-specific release record. Provider operations remain separate exact actions.
