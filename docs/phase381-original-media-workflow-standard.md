# Phase 381 — Original Media Workflow Standard

**Operating state:** browser-local preparation only; no recording, generation, upload, distribution, sale, or publication action.

| Step | Required record |
|---|---|
| Source | Original title, source/version, creator and contributor context |
| Rights | Master, composition/text, visuals, likeness, music, contributor permission |
| Accessibility | Captions, transcript, visual description, language, youth-support decision |
| Technical | Filename, format, duration/size where available, local integrity hash, master status |
| Release | Intended destination, territory/access, release copy, correction route, exact owner approval |

The workflow distinguishes local inspection from provider delivery. A filename, hash, browser preview, production note, or selected destination does not create a license, master, listing, product, player, distribution delivery, payment, token, wallet action, or public release.
