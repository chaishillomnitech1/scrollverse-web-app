# Phase 407 — Catalog Production Desk Structure

**Source context:** The owner-provided Spotify artist URL recorded in the local production slate, `https://open.spotify.com/artist/3P0GWluMPNZ2xSCVffVGAr`, together with the twelve locally indexed titles in the Direct-to-Fan Catalog and their corresponding planning packets.

## Purpose and current state

The Catalog Production Desk is a **reader-directed, release-gated** companion route. It makes the existing per-song planning packets legible in one place: a visitor can select a locally indexed title, read the original visual treatment lane, and see the source, rights, accessibility, contributor, destination, and owner-release fields that remain necessary before any media, catalog offer, or release can move forward.

The desk is an **available-now** planning and discovery route. Every item remains **research** until an item-specific release record establishes the exact source, final title/version, contributor permissions, accessible presentation, destination, free/paid decision, and explicit owner release.

## Per-song desk fields

Each title card will contain only the following original planning and evidence fields:

| Field | Desk treatment |
| --- | --- |
| Local record identity | Packet identifier and locally indexed title |
| Original visual concept | Original treatment lane from the production slate and packet |
| Source status | Exact master, title version, creator credit, and source location require an owner-controlled record |
| Rights and contributors | Composition, master, artwork, footage, performers, samples, marks, likenesses, and contributor context require item-specific records |
| Accessibility and youth safety | Captions, lyric sheet, transcript, audio-description plan, alt text, non-flashing review, and adult-supported participation guidance where relevant |
| Release conditions | Destination, free/paid decision, territory, metadata, date, and final owner release require an item-specific decision |
| Correction path | Source, credit, rights, title/version, or accessibility corrections travel through the release packet and co-creation pathway |

## Boundaries

The desk does not fetch or display audio from Spotify, create a sale, product, checkout, pricing page, wallet action, token, download, license, release date, public distribution record, contributor credit, royalty split, rights clearance, or production video. It does not establish that any pasted description, distribution statement, or release-ready label is currently true for a particular asset.

## Connected route map

The new desk is linked from the Direct-to-Fan Catalog and ScrollVerse Atlas. It provides return paths to Music Discovery, the Direct-to-Fan Catalog, the Atlas, the existing release-readiness route, and the Co-Creation Navigator. All connected destinations retain their own source and operating-state labels.
