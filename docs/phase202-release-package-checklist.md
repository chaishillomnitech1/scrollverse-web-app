# Per-Title Release Package Checklist

> **Purpose.** A book or media title must have a separate release record. A cover, catalog card, working file, provider link, price label, local checklist, or creative concept does not by itself establish rights, availability, payment readiness, delivery, accessibility, provider acceptance, or a live public edition.

| Lane | Evidence or preparation | Public-release limit |
| --- | --- | --- |
| Source and edition | Exact text/source, title, edition, contributor credits, and limitation language. | A manuscript draft does not establish final public content or a right to distribute. |
| Rights and permission | Creator/rightsholder basis, contributor terms, samples/excerpts, visual and translation permissions, and territory limits. | The creator must resolve rights before a platform or direct-reader release. |
| Accessibility | Alt text, reading structure, captions/transcript, and accessible alternative where applicable. | A check does not certify universal accessibility or substitute for appropriate review. |
| Media and integrity | Final export/master reference and a separate media review record. | A local source file or media preview is not a delivered public asset. |
| Catalog and delivery | Metadata, language, description, SKU/price and delivery rule if applicable, consumer terms, and target platform. | A catalog record does not establish an active price, checkout, listing, download, shipping, or delivery. |
| Owner release decision | Documented owner review, protected account/provider requirements, and public evidence after actual release. | No public release claim is made until the recorded action actually occurs. |
