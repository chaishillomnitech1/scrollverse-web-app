## Operating Model

The local Production Control Desk turns ScrollVerse’s creative lanes into exact asset-specific handoff packets. It is a production preparation and evidence-record tool. It does not publish an asset, connect an external account, process a payment, create a product, sign a wallet action, deploy a contract, or change a provider configuration.

## Asset-Specific Finalization Path

Each release begins with the local lane tool, then moves through one exact packet: final title/version; source and contributor/rights context; accessible materials; intended destination; operating state; correction path; and direct owner release. If the destination requires a platform account, merchant configuration, public network, payment, wallet, or store review, add the verified external result to that same packet only after it happens.

> A production lane can be ready for preparation while its public release, account connection, provider action, or network transaction is still pending. The record keeps those states precise rather than collapsing them into one claim.
