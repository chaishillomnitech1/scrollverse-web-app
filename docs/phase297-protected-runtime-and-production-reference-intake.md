The following structure can be reused for a fashion look, artifact, music release, book, comic, episode, visual, or production package. It is a **planning record**, not a public release or rights conclusion.

| Field | Required record |
| --- | --- |

| Rights and mark review | Originality, license/permission, character/brand/likeness, and contributor status before public use. |

| Correction path | A way to correct source, title, accessibility, or rights metadata without altering the original intake record. |
