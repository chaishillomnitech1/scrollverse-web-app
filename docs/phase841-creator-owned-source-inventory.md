## Central Migration Rule

ScrollVerse may consolidate **creator concepts, source labels, editorial summaries, and dedicated navigation paths** from these destinations. It will use original ScrollVerse visuals or controlled assets with explicit release direction for page artwork. It will not infer a payment state, account connection, storefront operation, provider relationship, commercial release, partnership, or other external operating state from a visible public page.

## Immediate Structure

The next central destination will organize the inventory into four visitor-facing lanes: **Story + Character Worlds**, **Visual + Fashion Worlds**, **Music + Media Worlds**, and **Game + Learning Worlds**. Each lane will preserve the source trail back to its creator-supplied destination.
